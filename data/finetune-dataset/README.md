# finetune-dataset

This folder contains the original CLEVR dataset used as the base data for fine-tuning.

- `original-clevr-train-scenes.json` — the original CLEVR train scenes file, unmodified from the source CLEVR dataset.
- `images/` — the original CLEVR images corresponding to the scenes above (e.g. `CLEVR_train_XXXXXX.png`).
